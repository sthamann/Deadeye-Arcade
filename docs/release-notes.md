# Deadeye Arcade 0.3.83

Choose your guns immediately before launching a game.

- Shoot the large P1 or P2 target with the gun you want to use, including a connected gun without a player assignment.
- Or select a player and choose from the connected gun list. Swap players, mix models or let P2 sit out.
- Confirm both player choices together. Game profile preparation receives the selected devices while preserving their learned buttons and firmware player identities.
- Launch with your saved setup without a new assignment. Single player titles show that P2 is unused.
- English and German text, large targets and layouts for smaller windows.

Adds preparation timing diagnostics for repairs and dependency inspection. These diagnostics do not yet resolve every reported slow launch or prove physical Start button behavior in Aliens Armageddon.

Validation includes generated TeknoParrot Start routes, saved hardware identities, duplicate input handling and the interactive selection flow. Physical gun tests remain separate from simulated input tests.
